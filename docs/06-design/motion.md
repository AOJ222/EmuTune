# Motion

Motion is refined and quick — the app feels fast, not flashy. A single easing curve and a small set of durations keep transitions coherent.

- `Motion.Easing` = `FastOutSlowInEasing`
- `Quick` 120 ms, `Standard` 220 ms, `Emphasis` 340 ms

## Guidance

- Prefer short, deliberate transitions on state changes (tab switches, recommendation reveal).
- Reserve emphasis for moments of progression/success (optimisation committed, rollback verified).
- Do not animate decoration for its own sake; motion should always clarify what changed.
