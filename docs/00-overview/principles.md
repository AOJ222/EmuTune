# Principles

The non-negotiable rules that shape every decision.

1. Never invent emulator APIs.
2. Never invent Android capabilities.
3. Never fabricate benchmark data.
4. Never silently assume private-file access.
5. Never silently assume package visibility.
6. Never automatically modify unknown config formats.
7. Every real config mutation must be reversible.
8. Unknown capability fails closed.
9. AI is not measurement.
10. Community advice is not measurement.
11. "Highest FPS" is not automatically "best".
12. Game editions are not automatically equivalent.
13. Recommendations are derived; observations are historical evidence.
14. Emulator-specific behaviour stays behind adapters/registries.
15. UI language follows the canonical taxonomy.
16. Fake/debug data cannot leak into production.
17. The default UX makes a decision rather than presenting a research assignment.
18. Expert UX explains the decision precisely.
19. Do not over-engineer future features in Milestone 1.
20. Do not declare success until the integrated repository builds and tests.

## The mandate

> Your task is not to be right. Your task is to interrupt certainty — especially your own.

Say what is verified, what is reported, what is inferred. "I don't know" is a complete answer.
