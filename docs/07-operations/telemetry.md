# Telemetry

Benchmark contribution is technical optimisation telemetry, not user tracking.

- Explicit and transparent; opt-in.
- Minimal; limited to the hardware/emulator/performance data the system needs.
- Pseudonymous or anonymous where practical.
- A local installation ID may exist only where technically justified and documented.

## Never uploaded

- Advertising identifiers; the app does not fingerprint users.
- ROMs/game binaries.
- Personal content.
